# Architecture Decision Record (ADR) 027: High-Demand Utility Catalog Expansion

## Status
Accepted

## Context
The platform's initial MVP catalog provided a strong foundation across Image, PDF, Text, Developer, and AI categories. To capture widespread organic search traffic, scale user engagement, and expand ad inventory, Phase 27 introduces high-demand utilities spanning Image processing, PDF document manipulation, Video/Audio tools, and QR/Barcode generation.

## Decisions

1. **Modular Adapter Pattern Reuse**:
   All new server-side utilities strictly implement the standard `UtilityAdapter<TInput, TOutput>` interface and register with `UtilityRegistry`. No divergent execution paths or external microservices were introduced.

2. **Isolated Dependency Architecture**:
   - **Image Tools (`image-to-pdf`, `image-resizer`, `image-cropper`, `webp-to-jpg`, `jpg-to-webp`, `png-to-webp`)**: Powered by `@napi-rs/canvas` and `pdf-lib`, ensuring high-performance native SIMD acceleration, memory bounding, and protection against decompression bombs.
   - **PDF Tools (`pdf-to-png`, `pdf-to-text`, `pdf-page-extractor`, `pdf-rotator`, `pdf-reorder-pages`, `pdf-watermark`, `pdf-metadata-remover`)**: Built upon `pdf-lib` and `pdfjs-dist/legacy`, using clean page-level transformations without arbitrary binary corruption.
   - **Media Tools (`video-compressor`, `mp4-to-mp3`, `video-to-gif`, `video-trimmer`, `audio-cutter`)**: Executed via a dedicated, safe `runFfmpegSafe` process runner utilizing `child_process.spawn` with strict argument array construction (no shell), 20–30s process timeouts, temporary file cleanup in `finally` blocks, and duration caps.
   - **QR Tools (`qr-code-generator`)**: Browser-native execution within `QrWorkspace` using HTML5 Canvas for zero server load and instant responsiveness.

3. **Explicitly Deferred Utilities**:
   - `word-to-pdf`, `pdf-to-word`, `pdf-to-excel`: Marked DRAFT/Deferred pending sandboxed document engine approval, avoiding unreliable partial conversions.
   - `heic-to-jpg`: Deferred to avoid unstable native bindings.
   - `pdf-password-protector`: Deferred pending verified AES-256 pure-JS encryption verification.
   - `instagram-video-importer` & `youtube-video-importer`: Deferred in compliance with terms of service, DRM, and anti-scraping policies.

## Consequences
- 18 high-demand production utilities added across 8 distinct categories.
- 0 regressions introduced to existing frozen utilities or Ad Engine.
- Resource limits, magic-byte validation, and filename sanitization enforced universally.
